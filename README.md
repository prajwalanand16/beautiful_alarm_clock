# Beautiful Alarm Clock

A modern, minimalist, and beautiful Flutter alarm clock application.

## 🚀 Features
- **Modern UI**: Clean, dark-themed design with gradients and smooth animations.
- **Real-time Clock**: A large, elegant digital display of current time and date.
- **Alarm Management**: 
  - Add multiple alarms with a native time picker.
  - Toggle alarms on/off.
  - Swipe to delete alarms.
  - Repeat day selection (Visual indicators).
- **Production Ready**: 
  - Configured with Core Library Desugaring for broad Android compatibility.
  - Signed release APK configuration.

## 🛠 Tech Stack
- **Flutter & Dart**
- **Provider**: State management.
- **Intl**: Date and time formatting.
- **Flutter Local Notifications**: (Configured for future implementation).

## 📦 Deployment
The application is pre-configured for release.
- **APK Location**: `build/app/outputs/flutter-apk/app-release.apk`
- **Signing**: Configured via `key.properties` (Excluded from git for security).
